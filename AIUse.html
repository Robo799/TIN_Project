AI Use Declaration — TIN_Project

Project: TIN_Project Type: Survival Game (Node.js + Canvas) AI Tool: ChatGPT

This document describes how AI (ChatGPT) was used during the development of this project. AI was used as a helper for guidance and example code; the final implementation was tested and adjusted by me.

1 Summary

  • AI tool used: ChatGPT (text assistant)
  • Main areas assisted: Movement logic, UI screens, sound handling
  • What I did myself: integrated changes into my codebase, fixed runtime issues, tested behavior in browser, adjusted UI/UX and balance
Important: AI did not run my code. I verified changes locally and resolved bugs (e.g., event handlers, screen switching, audio behavior).

2 Game logic (AI-assisted)

AI was used to propose patterns and example implementations for gameplay logic. I then integrated and modified the logic to fit my project structure and requirements.

Used AI for
  • Player movement (WASD / Arrow keys)
  • Enemy spawning rules and chasing behavior
  • Fixed issues caused by mixed “old” and “new” screen logic
Example prompt (approx.)
“How to make a simple player movement(WASD/Arrows) in js”

3 UI screens (AI-assisted)

AI was used to help design separate screens and provide a clear, defendable structure: Title Screen, Game Screen, and Game Over / High Score Screen.

Used AI for
  • Screen/state approach (show/hide blocks instead of routing)
  • HTML structure with separate containers (title/game/score)
  • High score table toggle (Scores ↔ Close button)
Example prompt (approx.)
“How to make separate title screen, game screen and game over/high score screen using HTML sections and show/hide logic.”

4 Sound (AI-assisted)

AI was used to help me with fixing some of the sound effects issues. I verified the behavior in browser and fixed issues related to state transitions.

Used AI for
  • Prevented sound spam with cooldown logic
  • Stopping game over sound when returning to title
Example prompt (approx.)
“How to stop sound when changing screens. How to add proximity sfx with cooldown so it doesn't freeze.”

5 Honesty statement

I used ChatGPT as a programming assistant (examples and debugging suggestions).
